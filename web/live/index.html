What is actually running?

Depth Anything V2 Small runs at 294 × 294 in a worker, with WebGPU when possible and a WASM CPU fallback. Raw relative inverse depth is mapped using two anchors, resampled to 128 × 128, distance-gated and evaluated by the same packed ten-split tree used in the Mojo comparisons. The JavaScript labels and reached leaves match all 98,304 numerical fixture pixels. The new causal tracker runs on CPU in this browser.

This is a new input experiment, not a reproduction of the original full-depth detector or a claim of HandNet training. The tree was trained on sensor depth; monocular depth can lose finger geometry and change scale across frames. Calibration and temporal smoothing cannot recover missing geometry. The phone, not the FPGA, performs this demo. No physical phone speed is claimed.

The app downloads code from jsDelivr and model weights from Hugging Face. Images are processed locally; there is no frame-upload endpoint. Network access is needed for the first load. On older phones, use CPU mode and expect slower updates. Stop releases the camera. Keep this page open while processing.
